# Scene Partner

Scene Partner is a private, locally run Windows chatbot for natural conversation and immersive roleplay.

## Download

Download the newest Windows installer from [Releases](https://github.com/HendrixSorel/ScenePartner/releases/latest).

The first launch downloads the local chat, voice, and illustration components. Allow roughly 35 GB of free space and keep the setup window open. The current build targets 64-bit Windows 10/11 with a modern NVIDIA graphics card and current NVIDIA drivers.

Windows may show an **Unknown Publisher** warning because this community build is not code-signed yet.

## Highlights

- Private local chat and roleplay with no Scene Partner account
- Official Qwen3 14B local chat model tuned for responsive roleplay
- 288 ready-made scenarios across 61 genres
- Character card maker and SillyTavern-compatible PNG/JSON imports
- Local neural text-to-speech and anime-style illustrations
- Long-conversation continuity, loop recovery, Continue, and suggested replies
- Local Rulebooks with visible story progression, seven tracker types, starter templates, and a visual maker
- Desktop and mobile-friendly interface with nostalgic messenger themes and a cozy Nature appearance
- Checksum-verified automatic updates

## Privacy

Conversations, personas, character cards, generated media, downloaded models, and runtime caches stay on the user's own computer. This repository hosts only official release downloads and the small update-feed file.

Private phone access can be enabled through Tailscale without opening a router port or making Scene Partner public.

## Current release

Scene Partner 1.3.0 adds local Rulebooks: visible, conversation-specific story progression that can track trust, affection, tension, health, supplies, time, changing states, collections, and dice outcomes. It includes a guided visual maker, reusable templates, safe editing and cleanup, manual corrections, and JSON import/export.

Rulebooks influence character behavior without deciding the player's feelings or choices. Progress belongs only to the conversation where it was earned and is included in portable backups.
